# VIM Guide

## Normal Mode

`i` - Insert mode

`esc` - Exit to Normal Mode

`u` - Undo

`ctrl + r` - Redo

`ctrl + D/U` - page 1/2 up, down

`/` - Search Mode

`w/b` - skip back/forward a word

`gg` - Skip to top of file

`G` - Go to bottom of file

`option/alt + i` - terminal window

`ctrl + n` - tree

`Ctrl + p` - fuzzy file search

`A` - move to end of line and insert mode

`o` - new line below and insert

`yy` - copy current line 

`y$` - copy from cursor to end of line

`p` - paste copied whole line below current line

`P` - paste copied whole line above current line

`gcc` - comment current line

`gcip` - comment a paragraph 

`dd` - delete current line

`d$` - delete from cursor to end of line

`zR` - open all folds in code (zfa to open singular one) (used when code section has been collapsed)

`:wq` - Write (save) and quit current window

`:w` - Write current changes

`:q` - Exit current window

`:qa` - Exit all windows

`:qa!` - Exit all windows forcefully (could lose changes)


# Visual Mode

`shift + v` - Enter visual mode (highlight with 'h' 'j' 'k' 'l') 

`y` - Copy highlighted selection

`p` - Paste highlighted selection
